# Kataloq görünüşü və mətn idarəetməsi

Admin paneli → Settings bölməsində **Kataloq görünüşü** seçimindən üç dizayndan biri seçilir:
- Kart kataloqu: standart şəkilli kartlar.
- Siyahı kataloqu: məhsul şəkli və məlumatları geniş sətirlərdə.
- Kompakt kataloq: daha kiçik kartlar və sıx yerləşim.

Ana səhifə yazıları bölməsində kiçik başlıq, əsas başlıq, açıqlama, kataloq başlığı/alt yazısı və footer mətni dəyişdirilə bilər. Hər mətnin ayrıca göstər/gizlət seçimi var. Loqo və banner üçün də ayrıca göstər/gizlət seçimləri mövcuddur.

Bütün seçimlər əvvəlki kimi Firestore `settings/catalog` sənədində saxlanılır. Dəyişiklikləri tətbiq etmək üçün **Bütün ayarları yadda saxla** düyməsini basın.
