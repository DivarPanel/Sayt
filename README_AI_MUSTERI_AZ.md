# DivarPanel — Müştərinin öz AI-si ilə məhsulu divarında sınaq

## Saytda
Məhsulun detallarını açın. "Öz AI-n ilə divarında sına" bölməsində:
- məhsulun birbaşa şəkil linki görünür və açılır;
- məhsul adı, kodu, ölçüsü, qiyməti və qiymət vahidi prompta əlavə edilir;
- düymə promptu kopyalayır.

Müştəri öz ChatGPT/Gemini və ya başqa şəkil qəbul edən AI tətbiqinə promptu yapışdırır, yalnız öz divarının şəklini və ölçülərini əlavə edir.

## Admin
Kateqoriyalar bölməsində ad dəyişmək, saytda gizlət/göstər, yuxarı-aşağı sıralamaq və silmək mümkündür. Gizlətmək məhsulları silmir.
Məhsul redaktəsində qiymət vahidini (ədəd, m², metr, dəst) seçin. Bu məlumat AI promptuna daxil edilir.

## Şəkil linki
Məhsul şəkli üçün birbaşa açılan HTTPS link tələb olunur. Link AI tətbiqinə əlçatan olmalıdır. Bəzi AI tətbiqləri URL-i özləri yükləməyə bilər; belə halda müştəri linki açıb şəkli cihazına endirərək AI söhbətinə fayl kimi əlavə edə bilər.

## Hesablama dəqiqliyi
Prompt AI-dən ölçü və kəsim planını hesablamağı istəyir, lakin AI nəticəsi texniki layihə və ya dəqiq smeta əvəzi deyil. Məhsulun real yerləşim sxemi, kəsim itkiləri və qiymət vahidi yoxlanmalıdır. Çatışmayan ölçülər varsa AI-dən sual verməsi tələb olunur.
