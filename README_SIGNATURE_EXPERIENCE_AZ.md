# DivarPanel.az — Signature Experience

## Yeni ana səhifə
- Qara mərmər estetikası və metal qızılı vurğular
- Şəkilli, toxunduqda açılan kateqoriya kartları
- Kateqoriya kartlarında həmin kateqoriyanın real məhsul şəkli və məhsul sayı
- Desktop-da mozaika, mobil cihazlarda iki sütunlu uyğun görünüş
- Mövcud məhsul kataloqu, axtarış, filtr, admin və müştəriyə xüsusi kataloq saxlanılır

## Admin-dən dizaynı dəyişmək və geri qaytarmaq
1. Admin → Sayt ayarları → Ana səhifə dizayn rejimi.
2. `Signature Experience — 3 konsept` və ya `Klassik kataloq görünüşü` seçin.
3. `Saytda önizlə` ilə yadda saxlamadan baxın.
4. Bəyənirsinizsə, dizaynı seçib `Bütün ayarları yadda saxla` düyməsini basın.
5. Köhnə görünüşə qayıtmaq üçün `Köhnə görünüşə qayıt` düyməsini basın.

Dizayn seçimi Firestore `settings/catalog` sənədində `homeDesign` sahəsində saxlanılır. Önizləmə URL parametridir və Firestore məlumatını dəyişmir.
